# 03: 步数、训练习惯与行动日历

**What to build:** 让本人可以记录每日步数、训练和习惯打卡；首页显示今日待办，日历展示完成状态，步数趋势随本地数据更新。

**Blocked by:** 02: 本人编辑权限与体重围度追踪

**Status:** ready-for-agent

- [ ] 本人可以新增、编辑和删除每日步数记录。
- [ ] 本人可以按日期完成、取消和补打训练与习惯。
- [ ] 今日待办包含体重、训练、习惯和步数目标。
- [ ] 日历详情可以查看并修改对应打卡。
- [ ] 步数趋势、7 日移动平均和目标线使用本地快照数据。
- [ ] 只读模式下所有步数和打卡修改入口不可用。
- [ ] 刷新页面后步数、打卡、待办和日历状态保持一致。
