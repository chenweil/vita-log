# 06.1-05: D1 备份、最小审计与故障 fail-closed

**What to build:** 为 D1 在线事实来源提供可恢复的备份路径、最小写操作审计和明确的故障行为，不复制完整健康数据作为审计日志。

**Blocked by:** 06.1-01, 06.1-02a, 06.1-02b

**Status:** ready-for-agent

- [ ] 使用 D1 平台恢复能力并定期导出完整 JSON 到受限离线位置，同时保留本机 SQLite 副本。
- [ ] 写操作审计只保存时间、操作类型、结果和版本，不保存健康数据内容或密码材料。
- [ ] 备份、恢复和导出接口需要本人会话；访客不能读取备份文件或审计内部字段。
- [ ] D1/Pages Functions 故障返回明确不可用状态，不回退缓存、本机 SQLite 或空数据。
- [ ] 测试覆盖备份失败、恢复前备份、审计字段过滤、数据库不可用、备份泄露和权限绕过。

> **不要顺手启用「恢复上一次快照」。** 平台恢复与离线备份**不是**同一种能力：`恢复上一次快照` 是提交时的单步回退，要的是 `loadRecovery()` 能取回**上一份快照**。本票交付的是备份与恢复**流程**，它不提供那个单步回退。因此在线模式下该按钮应当继续禁用，除非确实提供了可取回的上一份快照，并由 `HealthDataRepository.keepsRecoveryPoint` 如实声明为 `true`——该声明的语义见 `docs/adr/0002-cloudflare-realtime-public-access.md`。清空/导入的确认框与结果文案由同一个声明分流，改动它们时一并核对。
