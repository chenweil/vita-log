# 01: 独立静态应用与本地快照存储

**What to build:** 让轻盈计划成为不依赖 Workbuddy 的静态单页应用，使用版本化的浏览器本地健康数据快照加载现有仪表盘、设置展示、图表和日历，并在刷新后保留数据。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 页面不需要 `window.__SMART_PAGE__`、Workbuddy 注入脚本或 Workbuddy 数据库 ID 即可打开和运行。
- [ ] 前端、领域模型、存储契约和导入校验使用 TypeScript，并通过 Node.js 工具链完成构建和验证。
- [ ] 生产输出为静态资源；第一版不运行 Node.js 后端服务。
- [ ] 页面通过统一的健康数据仓库读取和提交版本化快照，而不是由 UI 直接读写浏览器存储。
- [ ] 快照包含 schema version、设置、体重、围度、步数、打卡和饮食记录集合。
- [ ] 页面刷新后能够恢复已保存的数据和派生展示。
- [ ] 存储损坏、不可用或写入失败时不会被当成空数据，界面会显示可操作的错误状态。
- [ ] 桌面和移动浏览器均能打开本地读模式的核心页面。
