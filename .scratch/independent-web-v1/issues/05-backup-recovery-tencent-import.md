# 05: 备份、恢复与腾讯历史数据一次性导入

**What to build:** 让本人可以导出完整 JSON 备份和各类 CSV，预览并导入腾讯云文档导出的历史数据；导入、清空和替换操作具有校验、冲突提示、恢复点和失败保护。

**Blocked by:** 04: 饮食记录与营养目标

**Status:** ready-for-agent

- [ ] JSON 备份可以完整保存并恢复设置和全部记录。
- [ ] 体重、围度、打卡、步数和饮食分别支持固定格式 CSV 导入或导出。
- [ ] 导入经过解析、校验、预览和确认四个阶段。
- [ ] 错误行、重复记录和冲突记录显示明确数量和原因。
- [ ] 导入失败不会改变当前数据。
- [ ] 替换或清空前会生成恢复快照，并可以主动恢复。
- [ ] 腾讯云文档只作为文件数据来源，不调用 API、MCP 或持续同步。
- [ ] 重复执行同一导入不会重复创建体重、围度、步数和打卡记录。
