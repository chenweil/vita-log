# 06.1-02a: Worker 认证原语与安全会话

**What to build:** 为 Pages Functions 提供可运行的密码校验和编辑会话，使本人登录后获得有限写权限，未登录、锁定或会话到期后恢复只读。

**Blocked by:** 06.1-01: D1 实时公开读取与公共投影

**Status:** ready-for-agent

- [ ] 使用 Web Crypto PBKDF2-HMAC-SHA-256、210,000 次迭代和独立盐，不依赖 Node `scryptSync`。
- [ ] 登录成功后创建 30 分钟绝对过期会话；锁定和注销立即撤销。
- [ ] 会话 Cookie 使用 `HttpOnly`、`Secure`、`SameSite=Strict`，写请求强制校验 `Origin/Host`，不开放 CORS。
- [ ] 登录和写接口按账号/IP限流，并返回稳定未授权、验证失败和版本冲突错误码。
- [ ] 本人会话下的普通版本化写入可用：带 `expectedVersion` 的健康快照保存成功，过期版本返回稳定冲突错误并保留未提交输入。本票只提供日常写路径；迁移、空库保护、预览与对账属于 `06.1-03`。
- [ ] 测试覆盖错误密码、会话到期、注销、Cookie 属性、跨站写请求、限流行为和已授权写入。
