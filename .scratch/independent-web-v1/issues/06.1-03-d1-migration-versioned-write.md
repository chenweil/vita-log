# 06.1-03: D1 迁移与版本化写入

**What to build:** 让本人把本机 SQLite/JSON 快照迁移到空 D1，并以版本化完整快照执行日常写入；迁移和写入在冲突或失败时不静默覆盖数据。

**Blocked by:** 06.1-01, 06.1-02a, 06.1-02b

**Status:** ready-for-agent

- [ ] D1 非空时拒绝自动迁移。
- [ ] 迁移预览展示来源、各类型数量、总数、日期范围、营养汇总、设置摘要和 D1 是否为空。
- [ ] 本人确认前不写入 D1；确认后完整导入并保留版本、时间戳和迁移结果。
- [ ] 迁移写入复用 `06.1-02a` 已交付的版本化写路径；本票只负责迁移专有的空库保护、预览、对账与原子性，不重新实现日常保存。
- [ ] 迁移失败、校验失败或数据库错误不改变当前 D1 快照。
- [ ] 测试覆盖空库迁移、非空拒绝、重复迁移、版本冲突、对账和原子失败保护。
