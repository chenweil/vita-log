# 04: 饮食记录与营养目标

**What to build:** 让本人可以录入、修改和删除饮食记录，按日期和餐次查看食物，并看到热量、蛋白质、脂肪、碳水和钠的每日汇总及目标进度。

**Blocked by:** 03: 步数、训练习惯与行动日历

**Status:** ready-for-agent

- [ ] 同一日期和餐次可以保存多条食物记录。
- [ ] 重复食物不会因为日期、餐次和名称相同而被错误合并。
- [ ] 饮食记录支持热量、蛋白质、脂肪、碳水、钠和备注。
- [ ] 每日汇总、营养目标对比和进度显示正确。
- [ ] 饮食记录出现在日历和最近记录中。
- [ ] 只读模式下饮食新增、编辑和删除入口不可用。
- [ ] 刷新页面后饮食记录和汇总保持一致。
