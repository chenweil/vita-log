# 06.1-04: 前端实时 owner/reader 集成

**What to build:** 让同一套页面在 Cloudflare 模式下默认以访客只读方式读取 D1；本人登录后可以编辑，保存后访客刷新读取最新数据。纯静态 `localStorage` 模式保持可查看和导出，但不再提供编辑入口。

**Blocked by:** 06.1-01, 06.1-02a, 06.1-02b

**Status:** ready-for-agent

- [ ] Cloudflare 模式默认读取 D1，访客不需要登录即可看到完整看板和最新已保存数据。
- [ ] 未登录、锁定和会话到期时隐藏/拒绝所有新增、编辑、删除、导入、清空、迁移、备份和恢复写路径。
- [ ] 登录后开启 owner 编辑；保存成功后状态和页面数据更新，访客刷新可看到新快照。
- [ ] 前端失败提示保留服务端错误码语义，不把数据库不可用当成空数据。
- [ ] 纯静态模式不再启用源码内置编辑凭据，保留只读查看和导出/非写入能力。
- [ ] 浏览器测试覆盖访客读取、登录编辑、锁定、会话到期、保存后刷新和直接事件/API绕过。
