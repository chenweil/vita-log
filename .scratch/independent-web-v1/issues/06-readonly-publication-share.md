# 06: 只读发布快照与分享页面

**What to build:** 让本人从当前本地快照生成一个不包含编辑能力和内部状态的只读发布快照，访问者可以打开并查看数据，但不能通过页面修改任何内容。

**Blocked by:** 05: 备份、恢复与腾讯历史数据一次性导入

**Status:** ready-for-agent

- [ ] 发布快照包含 schema version 和发布时间。
- [ ] 快照排除编辑凭据、会话状态、恢复数据和待处理操作。
- [ ] 只读页面隐藏或拒绝新增、编辑、删除、导入、清空和设置变更操作。
- [ ] 访问者无需登录即可查看发布数据。
- [ ] 页面明确显示数据发布时间，并说明它不是实时同步。
- [ ] 本地数据变化不会自动公开，发布必须由本人主动触发。
- [ ] 通过页面公开的只读数据不会写回本人的本地数据。
