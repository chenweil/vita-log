# 06.1: 实时公开读取与服务端编辑授权

**What to build:** 在 Cloudflare Pages + Pages Functions + D1 模式下，访客可以读取服务端当前已保存的最新健康数据；本人通过密码登录后才能编辑。保存成功后，访客刷新页面即可看到最新数据。服务端负责认证、会话和每次写入授权，前端编辑状态不是安全边界。

**Blocked by:** 08: SQLite 自托管持久化层

**Status:** ready-for-agent

- [ ] 未登录访客可以读取当前服务端快照，但不能读取密码摘要、会话、备份文件或内部存储状态。
- [ ] 本人通过服务端密码登录后获得限时编辑会话；未登录、锁定或会话到期时页面恢复只读。
- [ ] 新增、修改、删除、导入、清空、迁移、备份和恢复等写操作都由服务端逐请求授权；绕过页面直接调用 API 也会被拒绝。
- [ ] 首次管理员初始化不能被公网访客抢先完成；初始化入口、重置和恢复路径有明确的部署保护。
- [ ] 生产会话使用 HTTPS、安全 Cookie、明确的会话失效和注销行为。
- [ ] 登录和写入接口具有限流、跨站请求防护和稳定的未授权/版本冲突错误码。
- [ ] 访客读取的是 D1 当前在线事实来源；本人保存成功后，访客刷新可以看到最新数据，不要求重新生成发布 JSON。
- [ ] #06 的手动只读快照仍可作为独立的静态分享方式，但不再被描述为实时数据。
- [ ] 公网安全验收覆盖匿名读取、未授权写入、会话到期、注销、CSRF、初始化抢占、备份泄露和版本冲突。

## Open decisions

无。公网入口、初始化、公开字段、会话、备份、迁移和故障行为已在下方决定。

## Decisions — 2026-10-05

- 公网事实来源采用 Cloudflare D1，由 Cloudflare Worker/Pages Functions 提供实时读取和服务端写入授权。
- 当前 Node + 本机 SQLite 实现不直接作为公网主库；后续保留为迁移、备份或本地运维路径，具体边界待继续决定。
- 访客读取完整健康看板；未登录状态始终只读，只有服务端密码会话允许编辑。
- 首个管理员由部署时的 Cloudflare Secret/一次性运维命令预置，公网不开放账号初始化接口。
- 密码遗失只通过 Cloudflare Secret/运维命令离线重置，公网不提供找回入口。
- 首期公网编辑使用强密码、登录限流和短时会话，暂不引入 MFA；TOTP/Passkey 可作为后续增强。
- Cloudflare 运行入口采用现有 Vite 静态页面 + Pages Functions + D1，不改为 Workers 全栈入口。
- D1 成为唯一在线事实来源；本机 SQLite 仅保留为离线备份/恢复副本，不双写、不做在线镜像。
- 健康数据 API 使用 `no-store`，不由 CDN 缓存；本人保存成功后，访客下一次刷新读取 D1 最新快照，不做主动推送。
- 公开响应包含昵称、体重/体脂、围度、步数、打卡、饮食明细和备注；认证、会话、备份和内部元数据永不进入公开响应。
- API 与 Pages 使用同一域名；写接口不开放跨域 CORS，访客读取和本人编辑都通过同源 Pages Functions 进入 D1。
- D1 使用平台恢复能力，并定期导出完整 JSON 到受限离线备份；本机 SQLite 继续保留为离线恢复副本。
- D1 首次迁移要求数据库为空；迁移前展示预览并完成数量、日期和汇总对账，由本人确认后一次性导入；对账和备份完成前不开放公网读取。
- Worker 密码摘要使用 Web Crypto PBKDF2-HMAC-SHA-256，保存盐、迭代次数和摘要，不依赖 Node `scryptSync`。
- PBKDF2 沿用现有 210,000 次迭代；迁移时转换为服务端存储格式。
- 编辑会话沿用 30 分钟绝对过期；锁定和注销立即撤销服务端会话。
- 公网登录和写接口采用 Cloudflare Rate Limiting/WAF 与 Worker 内部按账号/IP 双层限流。
- 写请求使用 `HttpOnly + Secure + SameSite=Strict` 会话 Cookie，强制校验 `Origin/Host`，不开放 CORS。
- 公网写操作保留最小审计事件（时间、操作类型、结果、版本），不记录健康数据内容。
- D1 或 Pages Functions 故障时，访客明确看到数据暂时不可用；不回退旧缓存、本机 SQLite 或空数据。

## Comments

### 2026-10-05 — Created from revised access model

原 #06 已完成文件型只读发布快照。用户进一步确认：访客应看到服务端最新数据，只有本人密码登录后才能编辑。因此新增本票据承接实时公开读取、服务端授权和公网安全验收；不改写 #06 的原始完成语义。

### 2026-10-05 — Security and ticket-splitting decisions

纯静态 `localStorage` 模式转为只读；编辑统一进入 Cloudflare D1/Pages Functions。历史上公开的 `DEFAULT_EDITOR_AUTH` 凭据材料必须轮换、从源码移除，并在远端策略确认后重写历史。实现拆分见 `06.1-01` 至 `06.1-06`（其中 `02a`/`02b` 为两个独立安全票）。

### 2026-10-09 — PBKDF2 决策被 ADR-0002 取代

本票 2026-10-05 的「PBKDF2 沿用 210,000 次迭代」是历史记录，已被 `docs/adr/0002-cloudflare-realtime-public-access.md` 的「实现取舍（#06.1-06 补充）」取代。当前实现固定使用 PBKDF2-HMAC-SHA-256、100,000 次迭代；超过 Cloudflare 生产入口上限的凭据在本机解析阶段拒绝。不要从本票旧行派生部署参数；当前的目标环境 CPU 与真实登录验收仍以 `06.1-06` 的 pending 项为准。
