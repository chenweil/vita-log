# 06.1-01: D1 实时公开读取与公共投影

**What to build:** 让未登录访客通过同源 Pages Functions 读取 D1 当前在线快照，看到完整健康看板；响应不泄露认证、会话、备份或内部存储状态，并在 D1 不可用时显示明确错误。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] D1 保存版本化完整 `HealthSnapshot`，公共响应只投影昵称、体重/体脂、围度、步数、打卡、饮食明细和备注。
- [ ] `GET` 读取不要求登录，响应使用 `Cache-Control: no-store`，不包含密码摘要、会话、备份或内部元数据。
- [ ] 移除本机 `127.0.0.1` hostname 假设，Pages Functions 可以处理 Cloudflare 公开域名。
- [ ] D1/Function 失败时返回稳定数据库不可用错误；页面不回退旧缓存、本机 SQLite 或空快照。
- [ ] API contract tests 覆盖匿名读取、公开字段投影、敏感字段排除、no-store 和故障响应。
